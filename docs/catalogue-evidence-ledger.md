# Catalogue evidence ledger — foundation pass

**Status:** Source-backed research notes; not a recommendation list  
**Research date:** 5 November 2026  
**Catalogue policy:** A technology may enter `data/technology-catalog/catalogue.template.json` only after its record satisfies the JSON schema and every material capability, limitation, deployment claim, and compatibility rule has a source.

## How to read this ledger

- **Supported fact** is restricted to what the linked primary source documents.
- **Do not infer** records boundaries that stop a source from becoming an overbroad recommendation.
- **Potential input use** names the project constraint that may make the fact decision-relevant.
- No row assigns a score or declares a tool universally best.
