# Submission checklist — StackSense

## Before finalising the Drive folder

- [ ] Official problem statement, I/O requirements, and report template have been checked against this repository.
- [ ] All recommendation logic was created during the challenge window and is original.
- [ ] Source code is complete and free of secrets, API keys, personal tokens, and bulky generated files.
- [ ] `README.md` explains architecture, prerequisites, setup, run instructions, testing, and limitations.
- [ ] Project report has been rendered as a PDF and visually reviewed.
- [ ] Report includes input design, system design, screenshots, sample recommendations, and edge-case handling.
- [ ] Every API, dataset, library, and external source is cited with purpose and terms/licence where applicable.
- [ ] Public and adversarial scenarios have been tested, including infeasible and contradictory input.
- [ ] Screenshots were produced by the final submitted version.
- [ ] Dependency versions and runtime versions are pinned or documented.
- [ ] Google Drive folder uses the exact organiser-required structure.
- [ ] Folder sharing is set to “Anyone with the link can view”.
- [ ] Drive link opens in a private/incognito browser session.
- [ ] Submission occurs before 11:00 PM IST on 15 November 2026 (the earliest conflicting deadline shown on the event page).
